# GripperPlus 夹爪使用手册

本手册说明如何连接夹爪、完成首次准备，以及用命令控制开合和夹取。控制原理和参数见 [GRIPPER_CONTROL.md](GRIPPER_CONTROL.md)。

## 1. 连接方式

夹爪支持三种连接方式。三种方式使用同一套命令，可以同时连接，每条连接各自解锁、各自收到回复。

| 方式 | 当前固件 | 适合 | 说明 |
| --- | --- | --- | --- |
| USB | 启用 | 调试、烧录、看日志 | 唯一能看到固件日志的方式 |
| 蓝牙（BLE） | 启用 | 无线控制 | 设备名 `GripperPlus`，同一时间只能连一台电脑 |
| Wi-Fi | 已实现，默认关闭 | 需要更远距离或接入局域网时 | 开启方法见第 3.3 节 |

## 2. 准备

**硬件：**

1. 接通电机的 24 V 电源。
2. 用 USB-C 线把夹爪主控板接到电脑（只用蓝牙时，也可以只接电源）。
3. 两块触觉垫之间不要放东西。

**电脑软件（Windows / macOS / Linux）：**

```powershell
pip install -r host/requirements.txt
```

- 安装 PySide6（图形界面）、pyserial（USB）和 bleak（蓝牙）。
- 有两个工具，功能相同：
  - 图形界面 `host/4_gripper_gui.py`，见第 5.1 节；
  - 命令行 `host/3_gripper_cli.py`。
- 下文的命令都在仓库根目录运行。

## 3. 建立连接

### 3.1 USB

1. 在设备管理器里找到夹爪的串口号，例如 COM6。
2. 运行命令前，先关闭 `idf.py monitor` 等其他占用该串口的程序。
3. 运行：

```powershell
python host/3_gripper_cli.py --port COM6 calib
```

`--port` 默认是 COM6，与此相同时可以省略。

### 3.2 蓝牙

1. 打开电脑的蓝牙。**不要**在系统的蓝牙设置里"配对"夹爪，命令行工具会自己连接。
2. 查找附近的夹爪：

```powershell
python host/3_gripper_cli.py ble-scan
```

输出类似 `58:E6:C5:14:05:42  GripperPlus`。

3. 在任何命令前加 `--ble`：

```powershell
python host/3_gripper_cli.py --ble calib
python host/3_gripper_cli.py --ble close 50
```

4. 有多台夹爪时，用 `--ble-name` 指定地址：

```powershell
python host/3_gripper_cli.py --ble --ble-name 58:E6:C5:14:05:42 calib
```

- 连接约需 2–5 s，每条命令都会重新连接一次。
- 蓝牙同一时间只接受一台电脑。另一台电脑连着时，`ble-scan` 找不到它。

### 3.3 Wi-Fi（默认关闭）

**开启：**

1. 把 `firmware/main/app_config.h` 里的 `APP_ENABLE_WIFI` 改为 1。
2. 在 `firmware/` 目录里重新编译并烧录（`cd firmware`，再运行 `idf.py build flash`），然后运行 `home`。

**使用夹爪自己的热点：**

| 项目 | 值 |
| --- | --- |
| 热点名称 | `GripperPlus-XXXX`，XXXX 是 MAC 地址的最后 4 位，可用 `wifi-info` 查看 |
| 密码 | `gripper123`，在 `app_config.h` 的 `WIFI_AP_PASSWORD` 修改 |
| 夹爪地址 | `192.168.4.1`，TCP 端口 5000 |

电脑连上这个热点后运行：

```powershell
python host/3_gripper_cli.py --tcp 192.168.4.1 calib
```

注意：电脑连上夹爪热点后，会断开原来的 Wi-Fi 网络。

**接入已有的路由器（可选）：**

1. 通过 USB 保存网络：

```powershell
python host/3_gripper_cli.py wifi-set 网络名称 网络密码
python host/3_gripper_cli.py wifi-info
```

2. 过几秒运行 `wifi-info`，看路由器分给夹爪的地址，例如 192.168.1.57。
3. 同一网络里的电脑用 `--tcp 192.168.1.57` 连接。
4. 夹爪自己的热点仍然保留。用 `wifi-clear` 可以删除保存的网络。

## 4. 首次使用和每次开机

| 时机 | 命令 | 用时 | 结果 |
| --- | --- | --- | --- |
| 第一次使用，或机械结构改动后 | `calibrate` | 约 1.5–3 分钟 | 找到最大张开和最小闭合位置，存入夹爪 |
| 每次上电、复位或烧录后 | `home` | 约 40 s | 核对存储的位置，结束时停在闭合 5 %（最大张开） |

- 两条命令运行时，两块触觉垫之间必须空着。
- `home` 中途碰到东西会报错，取出后重新运行即可，存储的标定不会丢失。
- 所有开合和夹取命令都要在 `calibrate` 或 `home` 完成之后才能用。

## 5. 控制

### 5.1 图形界面

```powershell
python host/4_gripper_gui.py
```

**连接：**

1. 在右上角选择连接方式：USB、蓝牙或 Wi-Fi。
2. 选择目标：
   - USB：选串口，USB 串口排在最前；
   - 蓝牙：点"扫描"后从列表里选，或直接用默认名 `GripperPlus`；
   - Wi-Fi：填夹爪的地址。
3. 点"连接"。连接后会自动解锁。蓝牙第一次连接需要 5–20 s。

**左侧按钮：**

- 原点检查（home）、完整标定；
- 开合：闭合百分比和速度，以及"张开 5 %""50 %""合拢 95 %"三个快捷按钮；
- 力控夹取：夹持力和接近速度；
- 停止、清除故障；
- 电机断电，也可以按 Esc 键。

**右侧数据（每秒刷新 5 次）：**

- 状态和最近故障、位置和闭合百分比、目标力；
- ring 和 little 两块垫的力；
- 力矩和速度、电机温度、电机使能和故障码、标定位置；
- 最近 20 s 的夹持力曲线和闭合程度曲线；
- 命令结果和固件日志（日志只在 USB 连接时有）。

**导出数据：** 点"导出数据 CSV"，把连接以来记录的数据存到 `host/logs/gui_日期_时间.csv`。

### 5.2 命令行

下列命令用于所有连接方式；按连接方式在命令前加 `--port`、`--ble` 或 `--tcp`。

| 命令 | 作用 | 参数 |
| --- | --- | --- |
| `close <5–95>` | 移动到指定闭合百分比：5 = 最大张开，95 = 最大合拢 | `--speed v`：0.05–15 rad/s，默认 2 |
| `grip <力>` | 力控夹取，任意一块垫达到设定力即保持 | 0.5–20 N，0 = 默认 3 N；`--speed v`：接近速度，默认 2 |
| `stop` | 停在当前位置 | — |
| `disable` | 电机立即断电 | — |
| `clear` | 清除锁定的故障 | — |
| `calib` | 查看状态、标定数据、当前位置 | — |
| `calibrate` / `home` | 见第 4 节 | — |
| `cycle` | 往返测试 | `--count N`、`--speed v`、`--no-home` |
| `watch` | 实时显示位置和两垫的力；电机不通电 | — |
| `log` | 显示固件日志（仅 USB） | — |
| `wifi-info` / `wifi-set` / `wifi-clear` | Wi-Fi 状态和网络设置 | 见第 3.3 节 |
| `ble-scan` | 查找附近的夹爪 | — |

**例子：**

```powershell
python host/3_gripper_cli.py --ble close 5                # 张开到最大
python host/3_gripper_cli.py --ble grip 3                 # 3 N 夹取
python host/3_gripper_cli.py --ble grip 5 --speed 1       # 5 N，接近速度 1 rad/s
python host/3_gripper_cli.py --ble close 50 --speed 15    # 最快速度移到 50 %
```

**夹取过程：**

1. 夹爪比张开 80 % 更合拢时，先张开到 80 %。
2. 以接近速度合拢，碰到物体后转入力控，并保持设定的力。
3. 合拢到 95 % 仍没有碰到物体：报"未检测到物体"，回到张开 80 % 处。
4. 夹住后物体被拿走：同样回到张开 80 % 处。
5. 已经夹着物体时再发 `grip`，只改变夹持力，不重新开合。

## 6. 安全说明

- **随时可以停止：** 任何连接方式下，`disable`（电机断电）和 `stop` 都不需要解锁。命令运行中按 Ctrl+C，会立即让电机断电。
- **连接断开时：**
  - 正在移动：停在原地；
  - 正在夹持：继续保持当前的力，以免物体掉落；
  - 该连接的解锁失效，重新连接后要再解锁。命令行工具会自动解锁。
- **解锁：**
  - 会动电机的命令都要先解锁，每条连接单独解锁；
  - 解锁码 `0x47521000` 写在公开的代码里，只能防止误操作，不能防止他人恶意控制；
  - 蓝牙没有配对和加密，附近任何装了本工具的电脑都能连接，所以不要在无人看管时让夹爪处于可连接状态。
- **力的保护：**
  - 任一垫读数连续两次 ≥ 23 N，夹爪后退并停止；
  - 连续两次 ≥ 24 N，电机断电，需要 `clear`。
- **不要用手压**正在动作的夹爪，也不要把手指放在两垫之间。

## 7. 编写自己的上位机

三种连接方式传输同样的数据帧，格式和全部命令码见 [PROTOCOL.md](PROTOCOL.md)。

| 连接方式 | 发送命令 | 接收回复 |
| --- | --- | --- |
| USB | 串口写入，115200 波特率（USB 虚拟串口，实际不受此值限制） | 串口读取；数据帧和日志文字混在一起，按帧头 `A5 5A` 和 CRC 分离 |
| 蓝牙 | 写特征 `67700002-0000-0000-0000-676700001111`（可写、可无响应写） | 订阅特征 `67700003-0000-0000-0000-676700001111` 的通知；一帧可能分成多次通知，按字节流拼接 |
| Wi-Fi | TCP 连接端口 5000，直接写入 | 从同一连接读取；同一时间只接受一个客户端，新连接会顶替旧连接 |

蓝牙服务的 UUID 是 `67700001-0000-0000-0000-676700001111`。每条连接都要先发送解锁命令（操作码 0x07，参数 `0x47521000`）。

## 8. 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 命令返回 `ERR_STATE`，日志提示 `motor fault latched` | 电机驱动器报了故障 | 运行 `clear`，再运行 `home` |
| 命令返回 `ERR_LOCKED` | 这条连接还没解锁 | 命令行工具会自动解锁；自己写的程序要先发解锁命令 |
| `calib` 显示 `calibrated : no` | 上电或复位后还没核对位置 | 运行 `home` |
| `home` 报 `position frame changed` | 两垫之间有东西，或机械结构变了 | 取出东西后重新 `home`；仍然报错就运行 `calibrate` |
| `position` 一直是 0、日志反复出现 `probe … no feedback`，或界面"电机"显示"无反馈" | 电机驱动器卡在异常状态（2026-10-23 台架：每秒约 2000 次 CAN 格式错误，断电重启后恢复）；或电机没电、CAN 线松动 | 先把电机 24 V 断电约 10 s 再上电；仍不行再检查 CAN 线和收发器供电 |
| `ble-scan` 找不到夹爪 | 夹爪没上电、电脑蓝牙没开，或另一台电脑正连着 | 断开另一台电脑后重试 |
| 蓝牙命令提示 `cannot connect` | 距离太远或信号被遮挡 | 靠近到 5 m 以内重试 |
| 夹取时 `grip contact … peak` 很大 | 接近速度太快 | 降低 `--speed`，硬物体建议不超过 2 rad/s |
| 串口打不开 | 端口被 `idf.py monitor` 等程序占用 | 关闭占用串口的程序 |
