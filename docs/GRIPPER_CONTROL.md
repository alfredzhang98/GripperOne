# 夹爪电机控制说明

本文说明夹爪电机控制的用法、当前台架实测结果、工作参数范围和电流计算方法。硬件接线见 [../hardware/WIRING.md](../hardware/WIRING.md)，通信协议和传感器协议见 [PROTOCOL.md](PROTOCOL.md)。

## 1. 组成

| 部分 | 型号 / 位置 | 作用 |
| --- | --- | --- |
| 电机 | 达妙 DM-J4310-2EC（10:1 减速，24 V） | 驱动夹爪开合，工作在力位混合模式 |
| 指尖触觉垫 | 帕西尼 CP-M3025 × 2（ring、little） | 测量夹持力，量程 0–25 N，安全负载 50 N，输出频率 83.3 Hz |
| 主控 | XIAO ESP32-C6 | 通过 CAN（1 Mbit/s）控制电机，通过 UART 读取触觉 |
| 控制程序 | `firmware/components/gripper/`、`firmware/components/motor_twai/` | 标定、开合、力控夹取、保护 |
| 上位机工具 | `host/3_gripper_cli.py` | 命令行控制和测试 |

**力位混合模式：** 每一帧命令给驱动器三个量：目标位置、速度上限、电流上限。驱动器朝目标位置运动，但速度和电流都不超过上限。电流单位是 pu，1 pu 对应驱动器的最大电流。本电机 1 pu 对应输出轴 19.27 N·m（寄存器 Kt × Imax），命令分辨率 0.0001 pu，约 0.0019 N·m。

**位置表示：** 用"闭合百分比"表示。0 % 为标定的最大张开位置，100 % 为最小闭合位置，此时两垫相距 0.1 rad、不接触。命令只允许 5 %–95 %，两端各留 5 % 余量。

## 2. 命令行工具

运行前先关闭 `idf.py monitor`，同一时间只能有一个程序打开串口。需要 pyserial；用蓝牙还需要 bleak。在命令前加 `--ble` 即通过蓝牙控制，连接方法见 [USER_MANUAL.md](USER_MANUAL.md)。

```powershell
python host/3_gripper_cli.py [--port COM6] <命令> [参数]
```

带动作的命令运行中按 Ctrl+C，电机立即断电。动作结束后工具自动退出，电机仍保持在当前位置。

| 命令 | 作用 | 参数 |
| --- | --- | --- |
| `calibrate` | 完整标定，结果写入 ESP32 flash | 无；两垫之间必须空着 |
| `home` | 上电、复位或烧录后核对存储的标定 | 无；两垫之间必须空着 |
| `close <5–95>` | 移动到指定闭合百分比 | `--speed v`：0.05–15 rad/s，不给时为 2 |
| `grip <力>` | 力控夹取，单位 N | 0.5–20 N，0 = 默认 3 N；`--speed v`：接近速度 |
| `stop` | 停在当前位置并保持 | 无 |
| `disable` | 电机立即断电 | 无 |
| `clear` | 清除锁定的故障 | 无 |
| `calib` | 显示标定数据和状态 | 无 |
| `cycle` | 往返测试：先 `home`，再在 95 % 和 5 % 之间往返 | `--count N`、`--speed v`、`--no-home`；日志写在 `host/logs/` |
| `watch [--log]` | 实时显示位置、力矩和两垫的力；电机不通电 | 无 |
| `log` | 只显示固件日志 | 无 |
| `save-motor-config` | 把控制模式和通信超时写入电机 flash | 只做一次 |

**常用顺序：**

```powershell
python host/3_gripper_cli.py calibrate        # 第一次使用，或机械改动后
python host/3_gripper_cli.py home             # 每次上电、复位、烧录后
python host/3_gripper_cli.py close 5          # 张开到最大
python host/3_gripper_cli.py grip 3           # 3 N 夹取
python host/3_gripper_cli.py close 50 --speed 15
```

- 开机时如果驱动器报 0xD（CAN 通信丢失），固件会自动清除一次。这种情况是板子在电机使能时重启造成的。
- 其他故障需要用 `clear` 清除。

## 3. 标定与原点检查

**标定过程（`calibrate`）：**

1. 以 0.05 rad/s 张开，张开力矩的 0.5 s 平均值达到 0.36 N·m 时，判为张开端。
2. 回退 0.1 rad，记为最大位置（0 %）。
3. 触觉清零。
4. 合拢到任一垫读到 0.3 N，记为两垫接触位置；轻压两垫测电流到夹持力的系数 k；再回退，记为最小位置（100 %）。
5. 全部写入 flash，最后停在 5 %。

标定约需 1.5–3 分钟，取决于起始位置。

**原点检查（`home`）：**

- 电机输出轴编码器只记一圈内的角度，而行程约 7.2 rad，超过一圈，上电后读数可能整体差一整圈。
- `home` 慢速合拢到两垫接触，与存储的接触位置比较，误差在 0.03 rad 以内（或差一整圈加 0.03 rad 以内），就恢复存储的全部位置，再停在 5 %。约 40 s。
- 中途碰到物体时报错，提示取出后重试，不会作废存储的标定。
- 检查的是两垫接触位置（闭合端），不走到张开端；张开端由"存储的张开位置 + 实测差值"得到。
- 电机这次上电后已经完成过标定或原点检查时，`home` 不再检查，只移到闭合 5 %，当前标定保持有效（2026-10-29 起）。

**当前结果（2026-10-23 台架）：**

| 项目 | 值 |
| --- | --- |
| 最大位置（0 %） | −2.0853 rad |
| 最小位置（100 %） | +5.1337 rad |
| 两垫接触位置 | +5.2337 rad |
| 行程（最大到最小） | 7.2189 rad（413.6°），开口约 72 mm |
| k（电流 → 夹持力） | 1852.8 N/pu。轻压测量没拟合出有效值，这是用 19.27 N·m/pu ÷ 名义杠杆 10.4 mm 估算的 |
| 摩擦电流（接触附近，0.05 rad/s） | 0.0042 pu（0.081 N·m） |
| 起动电流 | 0.0176 pu（0.339 N·m） |

## 4. 开合运动

**驱动器设置：** 开机时写入驱动器内存，断电后恢复出厂值，每次开机重写。

- 梯形加减速度：ACC/DEC = ±80 rad/s²，出厂值 ±2；
- 位置环增益：KP_APR = 108，出厂值 54。

**速度：** 0.05–15 rad/s，不给时 2 rad/s，张开和合拢相同。按平均约 10 mm/rad 换算，15 rad/s 约为 150 mm/s。

**电流上限：** 按需要自动提高。

- 起始值：
  - 张开：1.0 N·m；
  - 合拢：I = max(I_move, I_off) + 3 N ÷ k（当前约 0.37 N·m）。
- 驱动器已用到上限、夹爪落后于预期位置但仍在移动时，每 100 ms 把上限乘 1.25。张开最多到 3.0 N·m，合拢最多到 1.0 N·m。
- 已用到上限并且 300 ms 不动：判为被挡住，停下并报 `move blocked`。
- 合拢途中，垫上的力比开始时升高 0.5 N 且至少 1 N，就停下。
- "开始时的力"取自本次合拢开始以来的最低读数，并且一直沿用到下一次张开移动：
  - 合拢途中又收到新的合拢命令（例如在界面上拖动滑块，每秒约 10 条），不会每条命令都重新取一次；
  - 因为碰到东西停下以后，再发合拢命令会立刻停下，不会每条命令再多压 0.5 N。要夹住物体请用"夹取"。

**实测（5 % ↔ 95 %，行程 6.4 rad）：**

| 速度 | 张开到 5 % | 合拢到 95 % | 越过目标 | 温度 |
| --- | --- | --- | --- | --- |
| 2 rad/s | 3.39 s | 3.40 s | 0 rad | — |
| 15 rad/s，固件计时 | 0.81 s | 0.88–0.89 s | 0 rad | MOS 29 °C，转子 28 °C |
| 15 rad/s，命令行计时，含约 0.1 s 轮询延迟 | 0.91 s | 1.00 s | — | 10 次往返温度不变 |

10 rad/s 和 15 rad/s 各连续往返 50 次，没有故障。到位位置的离散为 0.001–0.002 rad，这是电机编码器读数。

## 5. 力控夹取

**流程：**

1. 夹爪比张开 80 % 更合拢时，先张开到 80 %；否则从当前位置直接合拢。
2. 以接近速度合拢，目标为 95 % 位置。
3. 任一垫读到 0.3 N 时转入力控。
4. 合拢到 95 % 仍没有力：报"未检测到物体"，回到张开 80 % 处。

**力的测量：**

- 取两块垫中较大的读数，任意一边达到目标就算达到。两垫受力本应相等，读数小的一边是接触不均匀或夹指没对齐造成的。
- 触觉每 12.5 ms 读一次（80 Hz），传感器本身输出 83.3 Hz。
- 某个读数和上一个可信读数相差超过 8 N 时，先不用，等下一个读数确认。这是为了过滤触觉清零后偶尔出现的 25.5 N 错误帧。

**符号：**

| 符号 | 含义 | 当前值 |
| --- | --- | --- |
| F_t | 目标夹持力 | 0.5–20 N |
| F | 两垫中较大的读数 | — |
| k | 电流 → 夹持力系数 | 1852.8 N/pu |
| I_off, I_move | 标定的摩擦电流、起动电流 | 0.0042 / 0.0176 pu |
| I_f | 本次夹取的摩擦电流 | 接近时测得的滑动力矩峰值 ÷ 19.27 N·m/pu，不小于 I_off |
| db | 目标带半宽 | max(0.25 N, 4 % × F_t) |

**电流计算：**

| 阶段 | 公式 | 说明 |
| --- | --- | --- |
| 接近 | I = max(I_move, I_off) + 2 N ÷ k，不超过 0.6 N·m | 运动需要时按开合运动的规则提高；已到上限、夹爪不动 300 ms 而触觉没有力，判为物体在垫外 |
| 前馈 | I_ff = I_f + F_t ÷ k | 接触后立即给出 |
| 上限 | I_cap = 1.5 × I_f + min(2 F_t + 3 N, 30 N) ÷ k + ΔI | 1.5 倍用来克服静摩擦；ΔI 见下一行；总上限 0.06 pu（1.16 N·m） |
| 上限提高 | 力低于 F_t − db、垫上读到接触、夹爪不动、电流已到上限，持续 100 ms 时，ΔI 增加 0.03 N·m | ΔI 最多 0.30 N·m |
| 积分 | 每秒增加 2 × (F_t − F) ÷ k；夹爪不动时每秒至少增加 20 N ÷ k | 电流上升速度最快每秒 20 N ÷ k |

**被夹物体的刚度 K（N/rad）：** 每次修正的距离和速度都按 K 计算，所以软物体和硬物体都用同一套规则。

| 项目 | 规则 |
| --- | --- |
| 计算用的位置 | 50 ms 前的夹爪位置，与触觉读数的延迟对齐 |
| 初值和上限 | 存储的指腹刚度（两垫直接对压，目前 300 N/rad）。夹着物体时刚度只会比它低；K 偏高只会让修正偏小、偏慢 |
| 测量 | 取"从接触点到现在的割线斜率"和"最近一段的局部斜率"中较大的一个；位移至少 0.008 rad、力变化至少 1 N 才计算 |
| 测出之前 | 夹爪走了 Δx（≥ 0.01 rad）而力只升了 ΔF 时，K ≤ (ΔF + 0.5 N) ÷ Δx，软物体由此很快降低 K |
| 范围 | 3 N/rad 到存储的指腹刚度 |

**位置目标**（时间常数 T = 0.25 s，是触觉延迟 50 ms 的 5 倍）：

| 力的范围 | 处理 |
| --- | --- |
| F 低于目标带 | 目标在夹爪前方 (F_t − F) ÷ K，限制在 0.003–0.05 rad；速度上限 (F_t − F) ÷ (K × T)，限制在 0.02–1.0 rad/s |
| 在目标带内 | 停在当前位置。误差仍大于 db 并持续 300 ms 时，修正一次：移动 (F_t − F) ÷ K，速度 \|F_t − F\| ÷ (K × T)；往张开方向修正时，电流至少用 1.5 × I_f |
| F 高于目标带 | 电流按积分减小；位置目标以 (F − F_t) ÷ (K × T) 后退（0.01–1.0 rad/s），最多落后夹爪 (F − F_t) ÷ K（0.003–0.3 rad）。卸力另设电流下限：从 1.5 × I_f 开始，目标已落后到上限、夹爪仍不动时，每 100 ms 乘 1.25，最多 0.06 pu（1.16 N·m）。下限只在目标比夹爪更张开时使用；物体把夹爪推得比目标更张开时，目标改为跟着夹爪，不往回拉。所以多出的电流只会把夹爪往张开方向拉，不会增加夹持力 |
| F > min(F_t + max(1 N, 30 % × F_t), 22 N) | 电流立即降到 I_f + 0.5 F_t ÷ k |

目标带有回差：力进入 F_t ± db 时停住，之后要超出 F_t ± 3 db 才重新推或卸力。在这之间的误差由上面的"修正一次"消除。力在目标带内保持 150 ms 后，状态变为 `HOLDING`；力超出 F_t ± 3 db 时回到 `GRIPPING`。

**理想化仿真**（2026-10-29；线性物体，无摩擦，无电流上限，触觉延迟 50 ms，从接触时刻开始）：

| K（N/rad） | 3 N：最大力 / 进入 ±db | 8 N：最大力 / 进入 ±db | 8 → 1 N 用时 |
| --- | --- | --- | --- |
| 6 | 2.82 N / 1.05 s | 7.77 N / 1.50 s | 1.21 s |
| 54 | 2.82 N / 0.83 s | 7.76 N / 0.77 s | 0.58 s |
| 300 | 3.09 N / 0.33 s | 8.08 N / 0.51 s | 0.55 s |

仿真没有考虑摩擦、电流上限，也没有考虑海绵加载和卸载时刚度不同，只用来排除明显不稳定的 T；台架结果以实测为准。

**修改过程（2026-10-29，都还没有在台架上验证）：**

1. 手指夹取，目标 3 N：原来低于目标带时，不论差多少都推进 0.05 rad、速度 1.0 rad/s。手指的刚度约 54 N/rad，0.05 rad 就对应约 2.7 N，力在 2.7–4.8 N 之间反复振荡。于是加了目标带回差。
2. 目标从 7 N 逐步降到 0.5 N：两垫停在 4.9 / 4.3 N，电机力矩 −0.12 N·m、速度 −0.01 rad/s，力矩不够克服静摩擦。于是加了卸力电流下限。
3. 海绵，目标 8 N：力停在 7.1–7.7 N，原因是回差的 ±3 db 区间；8 → 1 N 时，6 s 内只降到 4.1 N，后退速度一直是固定的 0.1 rad/s（这块海绵约 6 N/rad）。于是改为按 K 计算，并加了带内修正。

**海绵实测（目标 3 N，2026-10-23）：**

| 接近速度 | 接触时 I_f / I_ff / I_cap (pu) | 0.5 s 内峰值 | 稳定后的力 | 接触到稳定 |
| --- | --- | --- | --- | --- |
| 2 rad/s | 0.007 / 0.009 / 0.015 | 2.6 N | 2.90 N | 0.83 s |
| 5 rad/s | 0.011 / 0.012 / 0.021 | 4.9 N，超过 4.0 N 后立即降电流 | 3.10 N | 1.53 s |

**接触冲击估算：** 每 1 rad/s 约 8–9 N。依据：输出轴转动惯量取 0.0027 kg·m²（转子 2.70e-5 kg·m² × 10²，读自驱动器寄存器），垫刚度假设 300 N/rad。硬物体还没测过，建议接近速度不超过 2 rad/s。

## 6. 工作范围与保护

| 项目 | 范围或阈值 | 依据 |
| --- | --- | --- |
| 夹持力 | 0.5–20 N，默认 3 N | 触觉量程 25 N 的 80 % |
| 速度 | 0.05–15 rad/s，默认 2 rad/s | 电机额定 12.6 rad/s，空载 20.9 rad/s（24 V，手册第 6 页） |
| 位置 | 闭合 5 %–95 % | 两端各留 5 % 余量 |
| 力矩 | 合拢 ≤ 1.0 N·m，夹取 ≤ 1.16 N·m，张开 ≤ 3.0 N·m，任何命令 ≤ 3.1 N·m | 电机额定 3.5 N·m，峰值 12.5 N·m |

**保护层级（由内到外）：**

| 层级 | 条件 | 处理 |
| --- | --- | --- |
| 驱动器 | 每帧的电流上限 | 硬件限流 |
| 夹爪 | 力超过 min(F_t + max(1 N, 30 % × F_t), 22 N) | 立即降电流并卸力 |
| 夹爪 | 任一垫 ≥ 23 N 或单个测点 ≥ 6 N，连续 2 个读数 | 后退 0.3 rad 并保持；标定中则停止 |
| 夹爪 | 标定中任一垫 ≥ 4 N | 中止标定并后退 |
| 夹爪 | 触觉中断 300 ms | 接近或合拢时停在原地；夹持中电流不再增加（不超过前馈电流），中断超过 10 s 结束力控并保持位置 |
| 监控层 | 电机使能时任一垫 ≥ 24 N，连续 2 个读数 | 电机断电，需要 `clear` |
| 监控层 | 驱动器报故障码 | 电机断电，需要 `clear` |
| 电机驱动模块 | 150 ms 没有新命令，或 300 ms 没有反馈 | 电机断电，重新检测电机 |
| 驱动器 | 300 ms 收不到 CAN 命令 | 驱动器自行断电，报 0xD |

## 7. 已知问题

| 问题 | 现状 | 依据 |
| --- | --- | --- |
| 张开端位置不稳定 | 按 0.36 N·m 判张开端，几次标定的最大位置在 −1.31 到 −2.20 rad 之间，约差 9 mm | 张开端附近力矩只比阈值低 0.02–0.06 N·m，而读数波动约 ±0.05 N·m。建议改为"接触位置 − 固定行程" |
| k 没测出来 | 用电机参数估算，1852.8 N/pu | 轻压测量拟合不成直线；夹持力由触觉闭环决定，k 只影响电流上限 |
| 两夹指略不平行 | 轻压时两垫读数不同，例如 ring 4.1 N、little 1.9 N | 控制用两垫中较大的读数 |
| 未测项目 | 硬物体夹取冲击、力的绝对准确度（砝码测试）、长期耐久 | — |
