# 帕西尼 PX-6AX GEN3 — 问题记录与给厂商的反馈

## 一、原始问题(已解决)

**现象**:高速通信集成板走 UART 时,只能识别到两颗 CP-M3025 中的一颗
(无名指近节 = 模组 12 正常,小拇指近节 = 模组 16 完全读不到);
同一块板改走 USB 直连官方上位机,两颗都正常。

**根因**:**集成板供电电压不足。** UART 模式下板子接的是 3.3V,
而 §4.3 规定 **供电范围 4.5~5V**。改成 5V 供电并给板子断电重上电后,两颗均正常识别。

**为什么很难查**:3.3V 下板子并不是完全不工作,而是"看起来完全正常":

| 现象 | 实测值 |
| --- | --- |
| 板子启动、UART 应答 | 正常 |
| 读版本号 `0x0000` | 正常返回 `ADAPTER_FW02.26` |
| 第一颗传感器(模组 12) | 完全正常,77 点、80 Hz、零丢帧 |
| 模组组合 `0x0010–0x0013` | `00 10 00 00` —— 第二颗**不在表里** |
| 第二颗点数 `0x0050` | `0` |
| 第二颗错误码 `0x0700+16×2` | `0x0001` —— 与**空槽相同**的码 |
| 读第二颗数据区 `0x3000` | 应答帧合法、状态字 0,内容全 `0x00` |

也就是说:板卡不报"通信故障",而是报"这个槽是空的",与真的没插传感器**完全无法区分**。

**唯一的线索是掉的那颗在扫描顺序里靠后**:板卡固定按
大拇指(0-3) → 食指(4-7) → 中指(8-11) → **无名指(12-15)** → **小拇指(16-19)** 扫描,
第一颗成功、第二颗失败,符合"加上第二颗负载后电压塌陷"的特征。

> 另外注意:模组表**只在集成板自身上电瞬间**扫描一次(§4.6),
> 所以仅仅把电压改成 5V 不够,必须让板子**完全掉电再上电**才会重新枚举。

## 二、给厂商的反馈(建议改进)

### 1. `0x0022`(DEVICE_RST)写 1 后板卡无法恢复 ⚠️

在 `ADAPTER_FW02.26` 上实测,发送:

```
55 AA 00 10 22 00 01 00 01 CD
```

之后板卡**对任何指令都不再应答**(已扫过 9600–1000000 全部常用波特率、
以及 TX/RX 两种接法,无任何字节返回),**必须物理断电重新上电才能恢复**。

请确认这是否为预期行为,以及该寄存器的正确用法和重启后应等待的时间。

### 2. 缺少 77 个测点的编号 → 物理位置对应关系

- 《用户手册》§5.6.2 只说明字节顺序(第 1 点 FX/FY/FZ、第 2 点 …);
- §3.2 只说明支架尾部绿点是坐标原点,**没有测点编号图**;
- 《通信盒协议》§4.6 分布力各行只写"依次为以下传感器模组",未说明模组内排列。

我们后来拿到 `Finger pad 指腹 M3025 … PXSR-STDCP03B.xlsx`(77 点三维坐标)才解决。
顺带一提,该阵列**不是 7×11 矩形**,而是 9 列(两侧外列各 7 点、中间七列各 9 点)
的弧面,X 跨 25.30mm、Y 跨 30.59mm、Z 从 2.70 鼓到 6.05mm,且列内点号不按 Y 单调。
**建议在手册中直接引用这份坐标表**,否则用户无法把数据还原到物理位置。

### 3. 错误码取值未定义

`0x0700–0x0737` 只说明"28 个传感器模组的错误码",没有任何取值定义。
实测 `0x0000` = 正常、`0x0001` = 空槽,其余取值含义未知。
另外 `0x0023`(TOTAL_ERR)说明写的是"有任意错误则**置 1**",实测返回过 `0x06`。

### 4. 两处文档笔误

- **掌心点数寄存器顺序与其它区域相反**:`0x0058–0x0067` 说明为
  "依次为掌心 8、掌心 7 … 掌心 1"(倒序),而合力区 `0x0500–0x05A7`
  和分布力区 `0x3800–0x3FFF` 都是掌心 1→8(正序)。
- **点数表地址范围前后不一致**:§4.6 的点数表明确到 `0x0067`
  (28 模组 × 2 字节 = 56 字节),但 `0x7000–0xE4FF` 那一行的说明写的是
  "根据 `0x0030-0x00AF` 确定的数据大小"。

### 5. 建议:供电不足应能被区分出来

如果板卡能在欠压时给出一个**区别于空槽 `0x0001`** 的错误码,
或提供一个可读的供电电压 / 欠压标志寄存器,
这类问题可以在几秒内定位,而不是逐一排查排线、传感器、协议和接线方向。
